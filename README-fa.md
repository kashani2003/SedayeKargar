# صدای کارگر – پروژهٔ ساخت APK

این پوشه همان نمونهٔ اولیهٔ اپ را در قالب یک پروژهٔ Capacitor دارد (فایل اپ: `www/index.html`).

## روش ۱: ساخت APK بدون نصب هیچ ابزاری (GitHub Actions)
1. در github.com یک حساب بسازید و یک مخزن (repository) جدید و خالی ایجاد کنید.
2. محتویات همین پوشه را (شامل پوشهٔ مخفی `.github`) در مخزن آپلود کنید.
3. به تب **Actions** بروید، گردش کار **Build APK** را انتخاب و **Run workflow** را بزنید.
4. بعد از چند دقیقه (حدود ۵ تا ۱۰ دقیقه) در پایین صفحهٔ اجرا، بخش **Artifacts** فایل `sedaye-kargar-apk` را دانلود کنید. داخل آن `app-debug.apk` است.
5. فایل را به گوشی منتقل و نصب کنید (باید «نصب از منابع ناشناس» برای مرورگر یا مدیر فایل فعال باشد).

## روش ۲: ساخت روی کامپیوتر خودتان
پیش‌نیاز: Node.js 18+، JDK 17 و Android Studio (برای Android SDK).
```
npm install
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug        # در ویندوز: gradlew.bat assembleDebug
```
خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`

## نکته‌ها
- این APK از نوع debug است و برای تست و نصب مستقیم مناسب است. برای انتشار در بازار (مثل کافه‌بازار یا گوگل‌پلی) باید نسخهٔ release با کلید امضای خودتان ساخته شود.
- شناسهٔ اپ (`appId`) را در `capacitor.config.json` به شناسهٔ سازمان خودتان تغییر دهید.
- ارسال پیامک، ورود و ثبت شکایت هنوز شبیه‌سازی هستند و به سرور واقعی وصل نیستند.
- فونت وزیرمتن از اینترنت بارگذاری می‌شود. بدون اینترنت، فونت پیش‌فرض گوشی نمایش داده می‌شود.
